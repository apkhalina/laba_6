Что такое Class<?>?
Это тип, который представляет любой Java-класс. Например: String.class, Integer.class, List.class.

• Целью может быть ТИП 
• Доступна во время исполнения программы

Создайте обработчик, который выводит список всех кешируемых областей или сообщение, что 
список пуст.


Решение:
@Cache — кешируемые области
Указываем, что целью может быть тип, доступна во время исполнения программы, имеет необязательное свойство value, типа String[], значение свойства по умолчанию: пустой массив.

Создаем класс с аннотацией, которая содержит три кешируемые области.

CacheProcessor.java
Создаём метод, который принимает объект, описывающий класс. Проверяем, есть аннотация. Если да, то извлекаем её свойство, представляющее собой список кешируемых областей, и выводим эти значения.
